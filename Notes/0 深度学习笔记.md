## 1 anaconda Python虚拟环境管理

### 1.1 anaconda命令

```c
// 1. 环境创建命令
conda create -n [名字] python=[版本号]
    eg：conda create -n ImageStudayPythonEnv python=3.14
    // ImageStudayPythonEnv 必须加
    // python=3.14 非必须选项
    
// 2. 创建完环境之后， 需要切换至对应环境进行使用
conda acivate [名字]
    eg: conda activate ImageStudayPythonEnv
        
// 3. 退出环境
conda deactivate
    eg：conda deactivate
        
// 4. 查看当前所有的虚拟环境
conda info --env 或者 conda env list
    eg：conda info --env 
    eg：conda env list

// 5. 删除虚拟环境
conda remove -n 环境名 --all
    eg：conda remove -n ImageStudayPythonEnv --all

// 6.复制当前环境为一个新的环境名字
conda create -n 新环境名 --clone 旧环境名
    eg：conda create -n oldEnv --clone NewEnv
        
tips：下载速度慢，可以修改源的地址，使用国内源
```
